# Notebooks

Notebooks are grouped by topic rather than placed in one global sequence.
Each topic owns its numbering, supporting material, and learning path.

Keep exploration here. Move code into `src/wave_part_dual/` when it becomes
useful outside one notebook, and add tests when its behavior should remain
stable instead of creatively evolving overnight.

During active practice, code may live directly in a notebook for quick editing.
When a notebook is finished, presentation-heavy machinery can move into its
topic's `_helpers/` directory. The polished notebook should keep experiment
parameters and important operations visible, with links for unusually brave
readers who want to inspect the backstage code.
